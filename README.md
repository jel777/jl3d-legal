# JL3D legal pages

These are the public privacy, support and terms pages for JL3D's iOS apps, served by GitHub Pages from this repo. It is the only public JL3D repo, and it holds nothing else.

Edit `build.py`, run `python3 build.py`, then commit the generated HTML. Every statement must match the shipping build of each app. When an app's data flows change, update this repo in the same release.
